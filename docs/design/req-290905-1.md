## 技术选型：
- 单体springboot 2.7.6
- mysql
- html

## 项目目标：
- 将各种股票数据落到数据库，并基于 html 提供增删改查功能
- [stock-list.json](../../resources/stock-list.json) 对应定义模型，落盘到股票列表数据表

```bash
curl --url 'http://api.waizaowang.com/market/c/daykline?symbol=stock&code=000001&period=1d&dividend=1&startDate=2026-09-01&endDate=2026-09-01&token=<在「接口配置」页 waizao_api_config 表维护的 token>' \
  -H 'Accept: application/json, text/plain, */*' \
  -H 'Accept-Language: zh-CN,zh;q=0.9,en;q=0.8' \
  -H 'Origin: http://www.waizaowang.com' \
  -H 'Proxy-Connection: keep-alive' \
  -H 'Referer: http://www.waizaowang.com/' \
  -H 'User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/152.0.0.0 Safari/537.36' \
  --insecure
```
```json
[
  {
    "t": "2026-09-01 00:00:00",
    "code": "000001",
    "o": 11.68,
    "c": 11.92,
    "h": 11.96,
    "l": 11.65,
    "v": 1523165,
    "a": 1807254400,
    "pc": 11.72
  }
]
```
- 根据上述 curl 和响应示例，提供对应 html 页面，支持单股票调试，单股票批量抓取，多个（页面手动通过股票列表选择）股票批量数据落库。以上都需要人工填写日期范围参数，具体接口文档在 http://www.waizaowang.com/apidoc 日K线数据。

## 交付标准
- web 系统正常启动，连接数据库
- 有管理页面，对 股票列表、股票日k线数据表 两个表有增删改查
- 提供k线渲染页面，支持查看指定股票的日k线图
- 支持数据批处理，对指定一个或者多个股票在指定日期范围内的日k线数据查询和落盘
- 表名定义规范为 shadowflow_xxx
- 所有批处理或接口调用功能，都需要提供对应调试页，并渲染结果（不做落盘处理）
