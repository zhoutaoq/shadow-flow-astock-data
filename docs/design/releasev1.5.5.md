### 实现说明

#### 一、「当日盈亏算的是错的」——错在哪

v1.5.4 及以前有两条口径叠在一起，导致当日盈亏在「当天买卖过」的标的上系统性偏错：

| 环节 | 旧口径 | 后果 |
|---|---|---|
| 买卖记账价 | 一律用**持仓成本价** | 卖出价恒等于成本价 → **已实现盈亏恒为 0**，卖出那部分收益根本算不出来，且「买 N 股再卖 N 股」以外的情况余额都不对 |
| 当日盈亏基准 | 一律用**昨收** | 当天买入的份额也被拿去和昨收比 → 把「买入价 ↔ 昨收」之间那段本不属于自己的涨跌记成了自己的盈亏 |

一个具体例子（600000，昨收 9.18）：当天以 **9.00** 买入 1000 股，现价 **9.10**。

- 旧口径：(9.10 − 9.18) × 1000 = **−80.00**（报表上「今天亏了 80」，但实际是赚的）；
- 新口径：(9.10 − 9.00) × 1000 = **+100.00**。

这个数字不是调参调出来的，而是「当天买入的份额，今天的起点就是买入价」——
券商 App 里的当日盈亏也是这么算的。

#### 二、新口径：按份额来源拆基准，折算「当量基准价」

一只标的的持仓可能由不同来源的份额混成，所以基准价按份额加权：

| 份额来源 | 基准价 | 口径标签 |
|---|---|---|
| 当天买入（「记一笔」里勾了「当天」） | **当日买入均价** | `当日买入均价` |
| 隔夜持仓（非当天买入） | **昨收** | `昨收` |
| 页面直接配置的持仓，且**建仓日 = 今天** | **成本价** | `建仓成本价` |
| 以上混在一起 | 按份额加权 | `昨收 + 当日买入均价（按份额折算）` |

```
当量基准价      = Σ(各来源基准价 × 该来源份额) ÷ 总份额
持仓浮动当日盈亏 = (现价 − 当量基准价) × 数量
当日已实现盈亏   = Σ(卖出成交价 − 该份额基准价) × 卖出数量
账户当日收益     = Σ 持仓浮动当日盈亏 + 当日已实现盈亏
当日收益率分母   = Σ(当量基准价 × 数量)
```

折算后的当量基准价与口径说明都直接渲染在持仓行里（`基准 昨收 + 当日买入均价（按份额折算）`），
用户能自己核对这个数是怎么来的，而不是只能看到一个结果。

昨收取不到时**不给假值**：该条不参与当日汇总，账户级收益率退化成不显示（`—`），
而不是拿一个凑出来的分母算百分比。

#### 三、记账口径必须一起改，否则已实现永远是 0

只改计算侧是没用的——只要还按成本价记账，卖出价就还是等于成本价。所以三条一起改：

1. **买卖改用真实成交价**：弹窗里的「成交价」预填该标的的**实时行情价**（取不到则留空由用户手填），
   用户可改成自己的实际成交价；老前端不带价格时回落到持仓成本价，行为不变。
   > v1.5.4 的预填逻辑是反的（有持仓就给成本价），那正好把这次要修的问题盖回去，v1.5.5 掉了个顺序。
2. **买入按加权平均重算成本价**：`新成本价 = (老成本市值 + 本次成交额) ÷ 新数量`，
   保证「买入那一刻账户总市值不变」，不会凭空多出一段盈亏。
3. **当日已实现落在账户上**：`shadowflow_account.day_realized_date` + `day_realized_profit`。
   日期不是今天就按 0 参与计算 —— **不需要任何定时任务**，跨天自然作废；
   持仓当天被卖光后，这份已实现仍然留在账户上不会丢。

配套的「当天买入池」（`shadowflow_position.day_buy_date / day_buy_qty / day_buy_amount`）同样按日期自动作废：
跨天后视为隔夜持仓，基准价自动切回昨收。卖出时按勾选状态优先冲当天买入池或隔夜份额，
池子按买入均价同比例扣减。

#### 四、界面改动

**① 期初市值 / 可用金额改为「不默认开放编辑」**

账户资金卡由可编辑输入框改成**只读键值对**（期初市值 / 可用金额 / 备注），
改动集中到右上角「维护」按钮弹出的弹窗里（`#fundMask`），打开时带入当前值。
卡片里不再有任何 `input`。

**② 买卖改成「记一笔」弹窗**

原来平铺在卡片里的表单整块移除，操作记录区只剩列头（方向 / 标的 / 成交价 / 数量 / 当日已实现 / 时间），
录入走「＋ 记一笔」弹窗：标的（搜索选择，支持手输 6 位代码）→ 方向（买 / 卖）→ 数量 → 成交价（选完标的自动带出实时价）
→ **「当天」勾选框**（默认勾选，文案随方向变：买入是「当天买入」、卖出是「卖的是当天买入的那部分」）
→ 一句口径说明。选择标的的回调里会去取实时行情价做预填。

**③ 建仓日（非必填）**

- 持仓表新增「建仓日」列（`yyyy-MM-dd`，共 11 列）；
- 添加 / 修改持仓的弹窗里放了 `<input type="date">` + 「选填」说明；
- 后端宽松解析：`yyyy-MM-dd` / `yyyyMMdd` / `yyyy/MM/dd` / `yyyy.MM.dd` 都认，空 = `null`，非法直接报错；
- 用例：**建仓日 = 今天**且没有当天买入池的持仓（用户在页面上直接配的），当日盈亏基准取**成本价**。

**④ 回测结果页 K 线补「当日涨跌幅」**

K 线 tooltip 由「开 / 高 / 低 / 收 + 成交量 / 成交额 / 均价」扩成「开 / 高 / 低 / 收 / **涨跌幅** + 成交量 / 成交额 / 均价」，
口径与「K线分析」页完全一致（`(收 − 昨收) ÷ 昨收`，红涨绿跌）。
**前收盘缺失时显示 `-`，不拿开盘价顶替** —— 那会把跳空缺口算成当日涨跌，看着就是错的。
