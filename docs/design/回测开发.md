## 回测功能如下：
1、回测配置：
- 账户起始金额
- 手续费滑点 (默认 0.01%，万分之一，必须 >= 0)
- 回测起止时间

2、买入/卖出策略 (组件化提供)
- 近n个交易日涨幅>x  / 近n个交易日涨幅<x (x可以是负数)
- 近n个交易日>m日线 / 近n个交易日<m日线
- 收盘价>n日线 / 收盘价<n日线 

说明:
- 第一个版本，每次买入和卖出都是全仓操作，不考虑分仓情况
- 买入和卖出支持配置多个策略，用 或/且 关系关联各个策略
- 回测结果需要提供阶段 k 线，带 bs 买卖点，同时提供盈亏金额和比例k线，下方提供每日的账户总金额，持仓金额，盈亏金额，比例，
- 买卖必须 100 股为最小单位
- 回测结果需要提供交易明细， 包括买入/卖出 股数，成本价，手续费
- 对于判断组件，可以考虑通过滑动窗口去实现取值判断逻辑
- 回测开始前，应当确认数据是否支持，包括供应商（默认且当前只提供waizao）、数据表（默认且当前只有日k），只判断起止两条数据，如果不全，错误提示，不回测。
- 回测必须指定股票和起止时间，回测结果需要落库 （回测页面展示的交易明细和盈亏情况，数据模型你自己考虑）
- 回测过程中所有百分比，都用小数参数格式，手续费滑点默认提供 %，0.01% 就是 万分之一
