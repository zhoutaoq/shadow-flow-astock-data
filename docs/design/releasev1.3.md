## releaseV1.3

feat: 

1、重构整个持久化过程，主要是以下逻辑
1-1、 模型统一定义，数据库和无数据库模式下逻辑统一，模型统一，只是持久化策略不一样
1-2、数据库模式下，采用 mysql 落库方式持久化数据
1-3、无数据库模式下，采用 ./data 目录为数据文件根目录，所有数据都应该以文件形式落盘，系统初始化时将所有持久化数据文件加载到neicunzhon使用
1-4、特殊情况不持久化到数据库，目前主要包括以下：
- K线数据
- 数据行超过一万的数据

2、开发环境下，项目启动的钉钉推送关闭掉，通过 yml 配置开关钉钉消息推送

3、saas 实现的基础，用户注册、超管账号默认 admin/1，密码通过启动环境变量控制，默认是1，用户需要支持注册，用户名必须是邮箱（注册校验用户名格式和唯一性），密码必须 6 位及以上，且必须同时包含字母和数字

4、saas 模式下，盯盘配置应该是跟用户的，系统默认的盯盘配置绑定在 admin 账号上。

5、admin 登录需要多一个页面，用户管理，分页展示系统用户，包括 admin 本身，支持修改 admin 和用户密码。

6、回测、盯盘等功能需要登陆后使用，首页和K线查看不需要登录即可使用。菜单全部统一成当前无数据库模式的菜单格式和内容，数据库模式下多余的菜单全部移除。
