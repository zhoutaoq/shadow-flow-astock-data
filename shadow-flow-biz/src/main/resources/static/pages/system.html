首页背景行情

股票名称跳转?全站的股票名称都会带上跳转链接，点击开新窗口。勾选的平台会出现在名称旁边（点名称本身直接开「默认」那个）；一个都不勾选时名称退回纯文本。

填了它，钉钉消息里点「本系统」就能打开本系统的页面；不填时消息会改跳下面已启用的站外平台。

外观与导航?系统 logo 与顶部菜单都属于「全站外观」，改完所有页面下一次加载即生效，不用重启服务。菜单只开放名称与顺序：地址、登录要求与超管权限由代码决定 —— 地址可配等于开一堆 404 死菜单，权限可配等于开越权入口。logo 支持 jpg / png / webp / gif，单张不超过 2MB；上传后存在数据目录，不会打进发布包。

出厂 logo
建议正方形、背景干净的小图；顶栏只占 26×26 像素。

第三方对接?平台自己对接第三方用的凭据，全局一份、全站生效 —— 行情抓取与系统通知（发布通知 / 注册通知 / 问题反馈）都从这里取值，改完即生效不用重启。令牌与 Webhook 只回显前后各 4 位；输入框留空表示这一项不动，要让它回落到配置文件的出厂值请点旁边的「清除」。注意：盯盘告警的机器人不在这里 —— 那是每个用户自己的推送通道，在「盯盘 → 推送」页各人配自己的；用户没配才落到这里的系统通知机器人。
