股票名称跳转

全站的股票名称都会带上跳转链接，点击开新窗口。勾选的平台会出现在名称旁边 （点名称本身直接开「默认」那个）；一个都不勾选时名称退回纯文本。

第三方对接

平台自己对接第三方用的凭据，全局一份、全站生效 —— 行情抓取与系统通知 （发布通知 / 注册通知 / 用户反馈）都从这里取值，改完即生效不用重启。 令牌与 Webhook 只回显前后各 4 位；输入框留空表示这一项不动， 要让它回落到配置文件的出厂值请点旁边的「清除」。
注意：盯盘告警的机器人不在这里 —— 那是每个用户自己的推送通道， 在「盯盘 → 推送」页各人配自己的；用户没配才落到这里的系统通知机器人。
