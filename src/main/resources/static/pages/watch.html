盯盘配置 需密码

盯盘会按固定间隔去查实时行情、超阈值时推钉钉机器人，属于要花钱、会打扰人的功能， 所以进入配置前先校验一次密码（维护在服务端 watch.password，不下发给浏览器）。
验证通过后本机本次会话内不再重复输入；关掉浏览器或令牌到期需要重新输入。

盯盘配置 保存后先写内存再落盘，无需重启

行情取自新浪财经，触发时按钉钉机器人推送。改完记得点「保存」： 配置会先更新到内存（盯盘立刻按新参数跑），再落盘到下面的文件，重启后依旧有效。
关掉后调度直接停止，不再查行情、不再推送。
每轮跑完再计下一轮；范围 5 ~ 3600 秒。
每条形如「过去 N 个轮询周期内累计涨/跌幅达 M%」（比如上方轮询间隔 60s、规则填 5，就是过去 300s）；涨跌幅分档：<1.5% 上涨 · 1.5%~3% 快速上涨 · ≥3% 急速拉升（下跌对称）。
输入代码或名称后从下拉里点选，点标签上的 × 移除。
包含 access_token；钉钉机器人"自定义关键词"需配 现价，否则消息会被钉钉服务端拒收

说明

项 说明
落盘文件 -（解析顺序：工作目录下的 watch-config.json → 服务端配置的绝对路径）
生效方式 保存即生效：内存里的配置立刻更新，定时调度按新间隔重新排，不需要重启进程
告警内容 多条规则任一命中即推；同一轮多条规则同时触发会合并为一条推送；涨跌幅超阈值、封板（涨停/跌停）、开板三类都会发；未配置钉钉 webhook 时只写日志
交易时段 只在周一至周五 9:30-11:30 / 13:00-15:00 查询；非交易时段不调接口，避免无谓消耗
